| **کم (Low)** | ۰.۱ تا ۳.۹ | **حداکثر ۹۰ روز تقویمی** | ادغام در به‌روزرسانی‌های هفتگی خودکار |

## ۳. قوانین سخت‌گیرانه ادغام خودکار (Auto-Merge Rules)

- **ممنوعیت مطلق ادغام خودکار (Zero Auto-Merge for Critical Packages):**
  - ادغام خودکار بدون بازبینی انسانی برای نسخه‌های اصلی (Major Releases) مطلقاً ممنوع است.
  - هرگونه به‌روزرسانی در پکیج‌های زیرساختی هسته (`@nestjs/*`، `next`، `react`، `prisma`، `@prisma/client`، `zod`) مستلزم بررسی دستی تغییرات (Changelog Review)، بررسی Breaking Changes و تایید لید فنی است.
- **شرط لازم برای پذیرش PR وابستگی‌ها:**
  - تمامی آزمون‌های خودکار و گیت‌های خط لوله (`npm run verify`) شامل ۲۰۴ تست خودکار، اعتبارسنجی توکن‌های DTCG، بررسی کنتراست رنگ WCAG، آدیت دسترسی‌پذیری و اسکن امنیت باید کاملاً سبز (Pass) باشند.
  - گزارش ممیزی لایسنس (`npm run license:audit`) نباید هیچ لایسنس محدودکننده یا ویروسی جدیدی را گزارش کند.

## ۴. گروه‌بندی وابستگی‌ها در Dependabot

پیکربندی در فایل [`.github/dependabot.yml`](file:///c:/Users/talas/OneDrive/Desktop/new_dragon_shop/brand-commerce/.github/dependabot.yml) ذخیره شده و به شرح زیر دسته‌بندی شده است:
1. **ابزارهای توسعه (`dev-dependencies`):** به‌روزرسانی هفتگی به صورت گروهی جهت کاهش بار و خستگی بازبینی کدهای پول‌ریکوئست.
2. **پکیج‌های زمان اجرای پروداکشن (`production-dependencies`):** به‌روزرسانی‌های مستقل با برچسب‌های مشخص، نیازمند بازبینی و تست دستی.
3. **اکشن‌های گیت‌هاب (`github-actions`):** بررسی ماهانه نسخه‌های با پین SHA یا تگ پایدار.
