## 1. Least-Privilege MCP Permission Matrix for Figma
In accordance with **TASK-197** and **TASK-185**, the Figma MCP integration is restricted to strictly scoped read-only access for design token synchronization and Code Connect component mapping.

| Permission Scope | Access Level | Permitted Actions | Prohibited Actions | Approval Gate |
|---|---|---|---|---|
| \`figma:read_nodes\` | Read-only | Fetch component geometries, variants, layers, and token values | Modifying canvas, deleting frames, creating assets | Auto-approved in dev |
| \`figma:export_images\`| Read-only | Export reference raster/SVG assets for visual QA comparison | Publishing or overwriting library assets | Auto-approved in dev |
| \`figma:code_connect\` | Read / Sync | Generate Code Connect mapping stubs and link to repository URLs | Committing code without local verify gate | Requires CI verify |
| \`figma:write_canvas\` | **BLOCKED** | None | Editing design canvas, altering styles, publishing libraries | **FORBIDDEN (Human Only)** |

## 3. Two-Way Token Parity Rule
- All mapped Figma components must strictly reference CSS variables generated by `scripts/export-dtcg-tokens.mjs` (`generated-tokens.css`).
- Hardcoded hex colors inside component JSX are prohibited by the automated architecture and security gates.
- Iranian Rial (`IRR`) minor unit integers are mandatory for all pricing component props.
