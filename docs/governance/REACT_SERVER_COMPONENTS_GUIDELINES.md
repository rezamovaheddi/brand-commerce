## ۱. اصل تفکیک مرز سرور و کلاینت (Server vs Client Boundary)

در فروشگاه لوکس Brand Commerce بر پایه Next.js 15، تمام کامپوننت‌ها به صورت پیش‌فرض **React Server Component (RSC)** هستند مگر آنکه صریحاً به تعامل مرورگر (Event Listener، State یا Effect) نیاز داشته باشند.

### ماتریس تفکیک کامپوننت‌ها:

| نوع کامپوننت | مشخصه | محل استقرار در پروژه | نمونه‌ها |
|---|---|---|---|
| **Server Component (پیش‌فرض)** | فاقد `'use client'`؛ اجرا روی سرور؛ رندر HTML استاتیک یا SSR | صفحات اصلی و لایه‌بندی (`app/**/page.tsx`) | `app/page.tsx`، `app/products/page.tsx`، `app/about/page.tsx` |
| **Client Component (برگ‌های تعاملی)** | دارای دستور صریح `'use client'` در خط اول فایل | کامپوننت‌های تعاملی در `components/*` | `CartDrawer.tsx`، `SkinQuiz.tsx`، `FloatingAudioDock.tsx` |

## ۲. الگوهای مجاز و بهترین تجارب مهندسی (Best Practices)

1. **فروبردن مرز تعامل به پایین‌ترین برگ درخت کامپوننت (Push State to the Leaves):**
   - هرگز کل صفحه (`page.tsx`) را به خاطر یک دکمه یا فرم کلاینتی نکنید.
   - محتوای متنی، هیرو، اطلاعات محصول و سئو باید سمت سرور بمانند و فقط دکمه افزودن به سبد خرید یا دراور کلاینتی شود.
2. **عدم اعتماد به داده‌های کلاینت در محاسبات مالی (Server-authoritative Pricing):**
   - کامپوننت‌های کلاینتی فقط شناسه تنوع کالا (`variantId`) و تعداد (`quantity`) را ارسال می‌کنند.
   - تمام قیمت‌ها، تخفیف‌ها، مالیات و مبالغ کل منحصراً در سرور و در واحدهای صحیح ریال محاسبه می‌شوند.
3. **پایداری چیدمان و تایپوگرافی راست‌به‌چپ (CLS < 0.1):**
   - استفاده از ابعاد صریح (`width` و `height`) در تصاویر و وکتورهای بسته‌بندی برای پیشگیری از پرش چیدمان.
   - عدم شکستن اتصالات حروف فارسی با حفظ قاعده `letter-spacing: 0`.
   - استفاده انحصاری از ویژگی‌های منطقی جهت‌گیری CSS (`margin-inline-start`, `padding-inline-end`).
4. **بارگذاری مشروط و استریمینگ با Suspense:**
   - بخش‌های نیازمند دیتای زنده با کامپوننت‌های اسکلت لوکس (`Skeleton`) کپسوله می‌شوند تا TTFB صفحه اول به حداقل برسد.

## ۳. الگوهای ضدامنیتی و ممنوعه (Anti-patterns Catalog)

| الگوی نامطلوب (Anti-pattern) | چرا ممنوع است | راهکار استاندارد جایگزین |
|---|---|---|
| **قرار دادن `'use client'` در `app/layout.tsx`** | نابودی رندر سمت سرور و کاهش شدید سئو | لایوت باید Server Component باشد؛ کانتکست‌ها در برگ‌ها کپسوله شوند. |
| **ارسال توابع یا کلاس به کلاینت** | خطای سریالایز نشدن در مرز شبکه | فقط داده‌های خالص JSON (آبجکت، آرایه، رشته و عدد) ردوبدل شوند. |
| **استفاده از مقادیر اعشاری پولی** | خطاهای تقریب ممیز شناور در امور مالی | ذخیره و انتقال ریال به صورت عدد صحیح (`priceMinor`). |
| **افشای کلیدهای محرمانه به کلاینت** | نشت اسرار امنیتی در سورس باندل | کلیدهای API و وب‌هوک فقط در محیط سرور (`process.env`) خوانده شوند. |
